# Changesets

Run `pnpm changeset` from the repository root to record a package change, its SemVer bump, and a release note. Packages version independently; select both only when both need a release.

Run `pnpm changeset:status` to review pending releases. CI configuration, development tooling, and repository-only documentation do not need a changeset.

See [the release workflow](../docs/release-workflow.md) for version PRs, npm authentication, and the publication switch.
